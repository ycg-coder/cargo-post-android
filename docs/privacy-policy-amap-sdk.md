## 一、SDK 基本信息（必须逐字出现在隐私政策里）

| 披露项 | 内容 |
| --- | --- |
| SDK 提供者公司名称 | 高德软件有限公司 |
| SDK 名称 | 高德地图 Android SDK（AMap SDK） |
| 使用目的 | 展示公交车辆与包裹运输轨迹的地图底图、站点与车辆标记、路线绘制；提供车辆定位能力 |
| 隐私权政策链接 | https://lbs.amap.com/pages/privacy/ |

## 二、收集和使用的个人信息类型

本项目引入的高德能力与对应采集项如下（按实际使用勾选，本项目实测用到前 3 项）：

| 能力 | 是否使用 | 涉及信息 |
| --- | --- | --- |
| 地图展示（`com.amap.api:3dmap`） | 是 | 设备信息（设备标识、系统版本、网络状态）、粗略/精确位置（用于地图定位与视口） |
| 定位（3dmap 内置 location 类） | 是（司机行驶中位置上报） | 精确位置、粗略位置 |
| 路线/轨迹绘制 | 是 | 起终点坐标（由业务数据提供，非 SDK 采集） |
| 搜索 POI | 否（现实公交站点层由后端服务端调用高德 Web 服务完成，客户端不调） | — |
| 导航 SDK | 否（本项目内置导航为自绘） | — |

## 三、本项目对高德 SDK 的实际调用边界（供审核溯源）

- 客户端只使用**地图展示 + 定位**两类能力，不调用搜索、导航、室内图等 SDK。
- 现实公交站点（高德 POI）由**后端服务端**通过高德 Web 服务获取后下发，
  客户端不直接请求高德 Web 服务，因此不涉及客户端侧的 Web 服务配额与 IP 白名单。
- 定位采集时机受限：仅在**司机端「行驶中/停靠」状态**下上报，切后台由前台服务按 10 秒节流，
  离开工作台立即停止（见 `driver/DriverLocationService.kt`）。

## 四、用户授权与撤回路径

- 权限声明（`AndroidManifest.xml`）：`ACCESS_FINE_LOCATION`、`ACCESS_COARSE_LOCATION`、
  `ACCESS_BACKGROUND_LOCATION`、`FOREGROUND_SERVICE_LOCATION`。
- 首次使用定位能力时由系统弹窗征得同意；拒绝后地图仍可展示，仅不显示"我的位置"。
- 用户可在系统「设置 → 应用 → 权限」随时关闭定位；关闭后高德 SDK 不再采集位置。
- 应用内路径：我的 → 设置 → 司机导航偏好 / 后台消息提醒，可关闭相关能力。

## 五、key 与签名（与合规无关但上架必查）

- 使用「**Android 平台**」类型 key，绑定 `PackageName` 与签名 SHA1。
- 正式包与调试包的 SHA1 不同，需在高德控制台同一 key 下分别填写。
- `debug.keystore` 因机器而异：**每台参与打包的机器都要取其 SHA1 并加入 key**，
  否则换机打包后地图会因签名不匹配而无法加载。
